# Operating-Lab-3---Tasks
# Operating Systems Lab 03 - Batch Scripting

This repository contains all the tasks from **Lab 03 (Batch Scripting & Windows Automation)**.
Each task is written as a separate `.bat` file that can be run on Windows.

## What is done

- **Practicals 1-8:** creating folders, creating files, user input, addition, pass/fail check, loops, and a complete automation script
- **Topic examples:** variables, IF/ELSE, IF EXIST, FOR loops, title and color
- **Worked examples and practical questions:** all solved as `.bat` files
- **Hands-on activity:** course workspace creator
- **Final lab task:** `student_record.bat` (takes student name, registration number and semester, creates a folder, saves the details in `student.txt`, makes a backup and shows the directory structure)

## Files

| File | Task |
| --- | --- |
| `00_hello.bat` | First batch file |
| `01` to `08` | Practicals 1 to 8 |
| `09` to `18` | Topic examples |
| `19` to `21` | Worked examples |
| `22` to `26` | Practical questions 1 to 5 |
| `27_hands_on_course_workspace_creator.bat` | Hands-on activity |
| `student_record.bat` | Final lab task |
| `report.txt`, `notes.txt`, `assignment.txt` | Sample files used by some scripts |

## How to run

1. Download or clone this repository.
2. Copy the files into a test folder, for example `C:\OSLabPractice`.
3. Double-click any `.bat` file to run it.

Note: do not run these scripts in important folders like `C:\Windows`. If a script shows an error that a folder already exists, delete the folder and run it again.
